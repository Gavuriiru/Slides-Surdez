# A surdez — Libras

Apresentação acadêmica em Reveal.js sobre o capítulo 3, “A surdez”, de *LIBRAS? Que língua é essa?*, de Audrei Gesser, em diálogo com o filme *E seu nome é Jonas* (1979).

## Apresentar

Acesse o site publicado pelo GitHub Pages:

https://gavuriiru.github.io/Slides-Surdez/

Abra em um navegador atualizado. Use as setas ou a barra de espaço para navegar. Pressione **S** para abrir as notas do apresentador.

A apresentação utiliza Reveal.js 5.2.1 e carrega fontes e imagens de fontes externas, portanto requer conexão com a internet.
